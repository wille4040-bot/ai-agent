# Köplägen — dagliga rapporter

Här sparas köplägesrobotens dagliga rapporter (`YYYY-MM-DD.md`), genererade av
`../scripts/koplagen.py`. Roboten screenar ett brett universum av aktier och
rankar dem efter hur undervärderade de är och hur bra köpläget är just nu.

Se `../scripts/KOPLAGEN.md` för hur roboten fungerar och hur du kör den.
